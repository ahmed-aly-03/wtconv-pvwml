Weekly research update — architecture note

Script 1: multitask WTConvNeXt (encoder–bottleneck–decoder + classifier)

Joint segmentation/classification model from the block-diagram design, built on the shared WTConvNeXt backbone — currently trained classification-only pending real PVWML masks

Shared encoder + bottleneck

  • A single, unmodified wtconvnext_tiny/small backbone produces features at 4 scales (56²→7², 96→768 channels); ImageNet-pretrained weights load directly into it.
  • A bottleneck (BN in the diagram) reuses the base model's own WTConvNeXtBlock, stacked twice, on the deepest features — keeps the new code consistent with the base architecture rather than introducing a different conv layer.
  • Both task branches read from this same bottleneck output, so the encoder gets gradient signal from whichever branch(es) below are actually supervised.

Classification branch — active today

  • GAP → Linear head off the bottleneck features → L_cls: cross-entropy, weighted by inverse class frequency computed automatically from the train split (not hardcoded).
  • This is the only branch with real supervision right now — no PVWML masks exist yet — so the model is fully trainable and useful today through this path alone.

Segmentation branch — present, gated

  • Standard U-Net-style decoder: 3 upsampling blocks with skip connections from encoder stages 0–2, ending in a segmentation head upsampled back to 224×224.
  • Loss is BCE + soft Dice (the standard combination for imbalanced pixel-wise medical segmentation), computed only over samples that actually have a mask — batches with none contribute exactly 0 to L_seg, so training degrades gracefully to classification-only.
  • Combined loss L = L_cls + λ·L_seg, with λ a plain CLI float (--seg-loss-weight) defaulting to 0.3 — not learned.
  • Turns on for real the moment --mask-dir is passed, pointing at either real annotations or the heuristic FLAIR pseudo-masks from generate_pseudo_masks.py (explicitly not ground truth).
Current status: no PVWML segmentation masks exist yet, so every run to date has trained the classification branch only. The decoder is fully wired and unit-tested (forward/backward verified), just waiting on mask data — either real annotations or the heuristic pseudo-masks from generate_pseudo_masks.py, which are explicitly not clinical ground truth.
Implementation: train_multitask.py, ahmed-aly-03/wtconv-pvwml. Backbone: WTConvNeXt (Finder et al., ECCV 2024).
