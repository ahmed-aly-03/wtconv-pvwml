Script 2: TDLF finetuning of WTConvNeXt

Two-stage decoupled training for PVWML classification under severe class imbalance

Stage 1 — Representation learning

  • Finetunes the pretrained wtconvnext_tiny/small backbone with an adversarial supervised contrastive loss (Khosla et al., extended with adversarial views), following Xiong et al., Decoupling Representation Learning and Classifier for Long-Tailed Adversarial Training, Pattern Recognition 172 (2026).
  • Each image gets two augmented views; PGD then crafts a bounded adversarial perturbation for each (ε=8/255, L∞) that maximizes the contrastive loss, producing a 4-view batch per sample: cleani, advi, cleanj, advj.
  • Positive pairs in the contrastive loss are defined by class label, not just shared origin image — this is what makes it directly address the long-tailed PVWML classes rather than being purely self-supervised.
  • Adversarial weight perturbation (AWP) adds a second forward/backward at temporarily perturbed weights before every optimizer step, targeting the robust generalization gap.
  • Rationale for decoupling: the paper's core finding is that rebalancing strategies matter for the classifier, not the representation — so Stage 1 optimizes purely for robust features, with no class-imbalance handling yet.

Stage 2 — Classifier learning

  • Backbone from Stage 1 is frozen; only a new linear head is trained on top of its pooled features.
  • Class imbalance is handled here, and only here, via class-balanced sampling (class drawn uniformly, then an instance uniformly within it) — matching the dataset's actual skew (e.g. vMCIAD ≈182 vs. Non-vascular ≈3848 images).
  • Loss is standard cross-entropy by default, with an optional Balanced Softmax variant available via a flag.
